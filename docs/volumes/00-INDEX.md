# LOIS documentation set

Prepared by Dustine Kibagendi, The Lucrebag, Nairobi. Confidential. Read Volume 1 first; the rest can be read in order or by need. Each volume carries a version and date. New volumes are added in sequence and never replace earlier ones, so the history of how LOIS was built stays readable.

| Volume | Title | For |
|---|---|---|
| 1 | Vision, scope and the product map | Everyone, first |
| 2 | Architecture and data | Developers, IT |
| 3 | Security, privacy and access control | Developers, IT, auditors |
| 4 | Build history, KB-001 to KB-023 | New developers |
| 5 | Use case hub, connectors and runs | Developers, integration partners |
| 6 | Operations: owner steps, smoke test, monitoring | Owner, operators |
| 7 | Integration partner guide | Integration partners |
| 8 | Roadmap: ERP, CRM, Odoo and Zoho, approved actions | Owner, planners |
| 9 | Legal drafts: NDA, restrictive covenants (for lawyer review) | Owner, advocate |

Reading order for a new developer: 1, 2, 3, 4, 5, then 6. For an integration partner: 1, 5, 7, then 9 once the NDA is signed.

Status of every claim in these volumes: "built and tested" means a test or database role test exists; "built, not seen live" means it passes tests and the production build but has not been observed on the public site; "planned" means it does not exist yet. Volume 4 is the authority on which is which.
